# LookingGlass 2

An unofficial modern continuation of LookingGlass, bringing live views of other Minecraft dimensions and worlds to mods via a rendering API.

> ⚠️ **Early Development:** Target platform is Minecraft **1.20.1** (Fabric, Forge, NeoForge). The project is currently in early setup stage; remote rendering is not yet functional.
